# Bridger Skin Archive

Catálogo de 156 stands, skins y objetos de Bridger con buscador, filtros por tier, favoritos locales y fichas de detalles.

Sitio: https://rorri-cm.github.io/bridger-skin-archive/

GitHub Pages publica desde la raíz de la rama `main`. Los datos son una copia de la hoja original; no se sincronizan automáticamente. SF Pro Display se usa si está disponible en el dispositivo, con fuentes de respaldo.
